    The agent

    A LangGraph pipeline in Python researches each app from public sources, extracts claims only where an official page supports them, cross-checks registries, then a separate pass looks for disjoint evidence. Every claim keeps its URL and excerpt.

    Run it

    python -m venv .venv; .\.venv\Scripts\Activate.ps1; pip install -r requirements.txt
python scripts/make_input.py                 # the 100 apps from the brief -> data/apps_input.json
python -m src.main research --ids 81,15      # small test run (Stripe, Pylon)
python -m src.main all                       # full run: research -> verify -> review -> insights -> report (resumable)
python -m src.main recheck --ids 81          # re-research one app with a fresh fetch
